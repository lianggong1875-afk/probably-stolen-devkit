## 二、被否掉的（我的错）

| 我写的 | 实际 |
|---|---|
| 「枪械鉴定」 | 原版鉴定只有三类：仿生手 `hand`、肋排堡 `ribwich`、等离子燃料 `plasma_fuel`。**没有枪械鉴定** |
| 「她的笔记教玩家看枪」 | 导师给的指南/放大镜是为那三类鉴定服务的，套到枪上是错的。改成给 `gun_part` / `match_barrel` |
| 「门关期她能卖枪、能派单」 | 原作的剧情角色是**按天排的事件**，一次只干一件事（乔治奥每来一次卖一批货，第 27 天白送一瓶） |

## 三、必须改的设计（重要）

### 3.1 门槛的获取路径是明确的——王尔德网络里卖许可证

```
武器许可证 I   | 300 | 治安部声望 ≥ 20 时下发，允许合法交易低级违禁枪械和弹药
武器许可证 II  | 600 | 声望 ≥ 50
武器许可证 III | 900 | 声望 ≥ 80
```

**这意味着**：玩家想去开芙蕾雅的门，路径是"刷治安部声望到 20 → 花 300 买 I 级许可证"，或者直接选枪匠开局。这是一个玩家能规划、能看见的进度目标，不是玄学条件。门槛设计成立。

### 3.2 许可证会被吊销 → 门槛不能是"一关就永远关"

> 「声望跌破 0 时被吊销。吊销时霰弹枪会一并收走。」

原版许可证是**可撤销**的。如果芙蕾雅的业务线跟着彻底关闭，玩家花 300 买的进度会清零，体验很差。

**改法**：
- 用两个标记：`everOpened`（首次满足即永久置位）与 `gateOpen`（实时）
- `gateOpen` 决定她**派不派单**、**开不开订阅**
- `everOpened` 决定她从"卖枪的散工"变成"能谈生意的人"这个**人物弧光不回退**
- 许可证被吊销时她说一句"你现在没资质了，单子我压着"，业务暂停但关系不倒退

### 3.3 「退休枪匠」已经占了"每周卖模组和弹药"的位置

```
退休枪匠 | 650 | 立即获得入门级武器改装设备。第二天到访，此后每周一次，出售枪械模组和弹药。
```

芙蕾雅如果也每周卖模组和弹药，就是重复角色。**差异化**：

| | 退休枪匠 | 芙蕾雅 |
|---|---|---|
| 定位 | 成品供货商，走量 | 派单 + 定制 + 人脉 |
| 卖什么 | 常规枪械模组、弹药 | **她自己做的模块**（+30~50%，无负面，贵）、公司渠道的高级枪/药/奢侈品 |
| 跟玩家的关系 | 你买他卖 | 你给她做活，她给你派客 |

### 3.4 睡前服务：不加冷却，做成"可每晚启用"

原作里 `可每晚启用` 的是盘查预警（10/晚）、买家推荐（10/晚）、卖家推荐（10/晚）；带冷却的是罪犯人脉（45/次，3 天）、超科技走私贩（500/次，5 天）。

用户要的是「每天晚上睡觉前可以选择勾选」——所以芙蕾雅的人脉服务应该是 **`totalCooldown = 0`，可每晚启用**，价格参考买家推荐的量级（10~30）。30 定得偏高但芙蕾雅给的是"指定雇佣兵"而不是随机买家，值这个价。

## 四、新发现：原作剧情角色的结构

从「按天速查」看，原作剧情角色是**按固定天数排好的事件序列**，每次出场只做一件事：

```
第 3 天  乔治奥：还回放射性废料（白送）
第 6 天  乔治奥：卖"远古外星遗物"（其实是废金属）
第 9 天  乔治奥：卖"未来之水"（改名的大号水瓶）
第 12 天 乔治奥：打折卖旧背包
第 27 天 乔治奥：送一瓶液体好运（第一瓶免费）
第 43 天 乔治奥：借钱造飞船
之后     乔治奥：从群星归来，还 4 倍
```

**规律**：
1. 每次出场 = 一个交易动作 + 一组对白，不重叠
2. 有口头禅（乔治奥全程第三人称自称）
3. 有三套分支台词：成交时 / 交易结束 / 被举报时
4. 有"白送"的节点（第 3 天、第 27 天）用来建立好感
5. 长线靠一个悬念（造飞船借钱 → 4 倍归还）

**对芙蕾雅的启示**：
- 我的 P0a/P0b 是两次出场，符合原作节奏
- **缺"白送"节点**：P0b 给 `gun_part` 应该明确是白送（不交易、直接放柜台），对应原作的"好心还给你"
- **缺分支台词**：原作每个节点都有"成交/不成交"两套。我的台词只有单线
- **缺口头禅**：乔治奥是第三人称，芙蕾雅需要一个可识别的说话特征（暂定：句子极短、先说数字后说理由、从不称呼玩家名字）
- 长线悬念：我写的 P8「档案室里的质检记录」方向对，但要像原作一样给一个明确的回报（原作是 4 倍还款）
