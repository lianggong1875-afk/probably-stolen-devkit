---
name: handoff
description: 把当前对话压缩成一份交接文档（handoff），供另一个智能体接手。
argument-hint: "下一个会话准备用来做什么？"
disable-model-invocation: true
---

写一份交接文档来总结当前对话，好让全新的智能体接着做下去。保存到用户操作系统的临时目录（`$TMPDIR`，没有就 `/tmp`；Windows 上是 `%TEMP%`），不要存进当前工作区。

文档里要有“建议技能”小节，写明下一个智能体该调用 Skill 工具加载哪些技能。

不要把已经记录在其他产物里的内容再写一遍（规格说明、计划、架构决策记录（ADR）、工单、提交、差异（diff））。改用路径或 URL 引用它们。

敏感信息一律脱敏，例如 API 密钥、密码、可识别个人身份的信息。

用户传了参数，就把参数当成对下一个会话重点的描述，并据此调整文档内容。
