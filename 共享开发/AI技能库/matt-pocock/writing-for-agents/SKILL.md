撰写智能体所消费的任何文档时的参考：技能、`AGENTS.md` / `CLAUDE.md`、通过指针抵达的文档。承载形式不同，写法相同：同样的杠杆让每一份都可预期，因为智能体每次运行走的是同一个_过程_，而不是产出同一份结果。

你正在写的文档是技能时，读 [`SKILL-MECHANICS.md`](SKILL-MECHANICS.md)，了解 frontmatter、调用方式的选择与路由技能。

## 上下文指针

**上下文指针**是保存在智能体上下文里的一个引用，它点名某份上下文之外的材料，并编码了抵达该材料的条件。技能的 description 就是一个；`AGENTS.md` 里指向某份文档的那一行是同一个对象。决定智能体何时抵达材料、抵达得多可靠的，是指针的_措辞_，不是它指向的目标。弱措辞的指针背后放一个必备目标，就是一处波动（variance）bug：先打磨措辞，只有打磨不成时才把材料内联进来。

指针干两件事：说明材料是什么，并列出应当触发抵达它的**分支**（分支是文档所处理的一个独立情形，因此不同的运行会在其中走不同的路径）。常驻加载的指针，每个字每一轮都在付费，所以它比正文更该下狠手删减：

- **把引导词（leading word）前置**：指针正是引导词做触发工作的地方。
- **每个分支一个触发。** 给同一个分支换名字的同义词，是把一个分支写了两遍；把它们合并，只保留真正独立的分支。
- **砍掉正文已自带的身份。**

## 两种负载

你添加的每一份文档与每一个指针，都花掉两种预算中的一种：

- **上下文负载**是常驻加载的材料在智能体窗口上产生的成本：`AGENTS.md` 的一行、一个技能的 description、任何每轮都待在上下文里的东西，无论是否触发，都在消耗 token 与注意力。
- **认知负载**是人这边的成本：有哪些文档存在，以及何时该去取哪一份。人就是索引。它不是要最小化的成本：它是人的主动性的代价；在人判断真正要紧的地方花它，在不要紧的地方把它去掉。

只通过指针抵达的材料，以指针自身那一行为代价，逃开了上下文负载；完全没有指针的材料，则完全压在认知负载上。

## 信息层级

文档由两类内容构成：**步骤**（智能体按顺序执行的动作）与**参考**（按需查阅的定义、规则、事实）。两者自由混合：全是步骤（一份操作流程）、全是参考（一次评审的规则、这份技能），或两者兼有。核心决策是每一块内容落在**信息层级**的哪一级，这是一把梯子，按智能体对该材料的需求有多迫切来排序：

1. **文件内步骤**是主层级：智能体做什么，按顺序。
2. **文件内参考**按需查阅。它常常是一组正当平级的同辈内容（一次评审的每条规则都在同一级），这是妥当的安排，不是坏味道。
3. **外放参考（disclosed reference）**被推到单独的文件里，通过上下文指针抵达，只在指针触发时加载。其范围从同目录下的兄弟文件，一直延伸到完全外部的参考，那种参考放在任何位置，任何文档都可以指向它。

往下推得太少，顶层就臃肿；推得太多，你又把智能体真正需要的材料藏了起来。这个张力就是决策的全部。

**渐进式外放（progressive disclosure）**是沿梯子向下移动（移出主文件、放到指针之后），好让顶层保持可读。它首要目的不是省 token：它是保护层级的方式。分支是最干净的外放测试：每个分支都需要的内容内联，只有部分分支会抵达的内容推到指针之后。文档有步骤时，本该外放的文件内参考会把它们埋掉，把“认真对待步骤”变成掷硬币：这是波动杠杆，不只是可读性杠杆。

**就近安置（co-location）**是文件内的配套规则：梯子决定一块内容待得多深，就近安置决定它到位以后旁边放什么。把一个概念的定义、规则与注意事项放在同一个标题之下，不要打散，这样读其中一部分就会把邻居一起带来。测试方法：文档读起来应当像专为智能体写的说明文档。聚拢的材料读起来是这样；打散的材料不是。（与重复不同：重复是把一个意思在两处都写；打散是把一个意思碎成许多片。）

**蔓延（sprawl）**是这里的失效模式：文档就是太长，即便每一行都活着且独一无二。注意力在多余的部分上被摊薄，而每一行多余都是又一行要保持相关。解药是梯子：把参考外放到指针之后，并按分支或顺序拆分，让每条路径只携带自己需要的东西。

## 步骤与完成标准

每个步骤都以一条**完成标准**收尾，也就是告诉智能体工作已完成的那个条件。两个属性让它成为杠杆：

- **清晰度**：智能体能分辨做完与没做完吗？模糊的边界（“理解达成了”）会招来**提前完成**：在真正做完之前就结束步骤，注意力滑向_已经做完_这件事。还看得见的后续步骤（**完成后步骤（post-completion steps）**）提供拉力；标准的清晰度是阻力。按顺序防御：**先打磨边界**（局部且便宜）；只有当边界模糊到无法再分_并且_你确实观察到抢工，才用拆分序列的办法把后面的步骤藏起来。藏起来只在真正的上下文边界处有效（交接或派发子智能体；内联调用会把后面的步骤留在上下文里，什么也没清掉）。
- **要求量**：它要求多少。“所有被改动的模型都有交代”会逼出彻底的工作，“产出一份改动清单”则不会。要求量驱动**细工（legwork）**（智能体在工作内部做的挖掘，潜藏在措辞里，而不是写成一个独立步骤），并且它不受步骤限制：“每条规则都适用”约束一整块平级参考，正如“每个步骤都做完”约束一个序列，这就是为什么一份全是参考的文档照样带一条穷尽性门槛。

最强的标准既可核验，又穷尽无漏。

## 何时拆分

把一份文档拆成两份，要花掉两种负载中的一种，所以只有切法值回票价时才拆：

- **按顺序拆**：当完成后步骤会诱使智能体抢它眼前这一步时，就把这一串步骤拆开。把它们挡在视野之外，能在当前任务上逼出更多细工。反向操作要当心：合并序列会让每一步的后续步骤暴露给后面的内容，招来提前完成。
- **按调用方式拆**，这一条是技能专属的：见 [`SKILL-MECHANICS.md`](SKILL-MECHANICS.md)。

## 引导词

**引导词**是已经活在模型预训练里的紧凑概念，智能体在运行文档时用它来思考（_课程_、_战争迷雾_、_曳光弹_）。它以词的形式反复出现，绝不以句子的形式出现，靠招募模型已有的先验，累积出一份分布式定义，用最少的 token 锚住一整片行为。自造词只要定义清楚也能用，但自造词招募不到先验：预先训练过的词免费给你的东西，你得用定义 token 去付；先伸手去拿已有的词。

它在两处起锚定作用。在正文里锚_执行_：词一出现，智能体每次都伸手去取同一个行为；在平级参考里，它把注意力收拢到要找的那一类东西上。在指针里锚_调用_：当同一个词同时活在你的提示词、你的文档和你的代码库里，智能体会把这套共用的语言与材料关联起来，更可靠地抵达它。

主动去找用引导词重构的机会。一个三连词在三处分别铺开写，一个指针花一整句去指一个念头。每一处都是求着被压缩成单个词的一段文字：

- “快、确定、开销低” → _紧凑_（一个 _紧凑_ 的循环）。
- “一条你信得过的循环” → _红_，把一个模糊的关卡变成二值可观测状态（循环在 bug 上变 _红_，或者没变）。

你赢两次：token 更少，而且给智能体一个更利的钩子来挂住它的思考。假定每份文档都带着一堆能被引导词淘汰掉的重述。去找出来。

**否定**是这把杠杆旁边的失效模式：用禁令去操纵，会把被禁的行为拽进上下文，让它变得_更_容易取用，而不是更难。_别想大象_，于是脑子里只剩下大象；否定是个弱修饰语，被强烈激活的概念一冲就盖过去，于是禁令有一半读起来像“去做那件事”的指令。要提示**正面**：把目标行为说出来（“写单行注释”），让被禁的那种根本没被说出口。只有当一条禁令是你无法正面表述的硬护栏时，它才配占位置；即便到那时，也要配上正面目标，让注意力落在该做什么上。

## 删减

- 让每个意思都待在**唯一真相来源**里：一个权威位置，这样改行为就是改一处。**重复**（同一个意思出现在不止一处）既花维护又花 token，还会把一个意思在梯子上的显眼度抬到高于它真实的位次。（它是引导词的意外反面：引导词刻意重复一个词，绝不重复那个意思。）
- **环境**也是真相来源（`package.json` 的脚本、配置文件、目录结构、`--help` 输出），而重述环境的文档是一层**缓存**：一份查询结果的副本，只有在查询昂贵时才值回它的负载。缓存智能体靠看找不到的东西：没写下来的约定、某个选择背后的理由、任何配置都不肯承认的坑。一次看一个文件、一条命令就能查到的，交给环境，那里不会过期。
- 逐行检查**相关性**：它还跟这份文档要做的事相干吗？一行失去相关性，要么因为它从不与任务相干（纯铺垫，或一个本该外放的分支），要么因为它所描述的行为或世界改变而变旧。更短的文档更容易保持相关。没有删减纪律，默认命运就是**沉积**：陈旧的层沉积下来，因为加东西感觉安全、删东西感觉冒险，直到你必须一路钻穿它们才找得到还活着的东西。
- 逐句猎杀**空转项（no-ops）**：一条模型本来就默认遵循的指令，付了负载却什么都没说。判断方法（它相对默认行为有改变吗？）是相对模型的，不是相对读者的：两个人为某个空转项争执，其实是在为默认行为争执，解决方法是把文档跑一遍，不是辩论。一句话测试不通过，就删掉整句，不要从里面抠字。这个测试也给引导词打分：一个弱到打不过默认的词（智能体本来就大致彻底时写 _彻底_）就是空转项，改法是换一个更狠的词（_不留情_），不是换一种技巧。
