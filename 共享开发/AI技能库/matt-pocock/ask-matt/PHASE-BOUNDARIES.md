# 阶段边界

**阶段**是会话里的一块工作：那段拷问、那段实现、那段质检。这个定义故意留糊：当你想「行了，这块完了」的时候，一个阶段就结束了。

**阶段边界**是两个阶段之间的缝，也是这个决定唯一该出现的地方。阶段中途没有决定可做：继续，或者把剩下的活拆给子智能体。在阶段中途做压缩会让智能体掉线丢线索。

## 五个选项

| 选项 | 它做什么 |
| ------------ | --------------------------------------------------------------- |
| **继续** | 留在本会话。完全不切上下文。 |
| **`/clear`** | 清空上下文窗口，从零开始。 |
| **`/handoff`** | 写一份可携带的 markdown 文件，用它在地球上任何地方播种一个会话。 |
| **子智能体** | 把任务送进它自己的上下文窗口，拿回一份报告。 |
| **`/compact`** | 压缩当前上下文，用这份摘要播种一个新会话。 |

## 判定树

在边界上从上往下走。第一个**是**即命中。

**1. 你能在这个会话里继续吗？** 两件事会让答案变「是」：下一阶段需要这一阶段作为**一手来源**，或者你还剩足够的[智能区间](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（约 150k token）装得下下一阶段。拷问 → 实现是标准的「是」：实现要的是逐字的推理本身，不是它的摘要。继续不花代价也不丢东西，所以先把它排除掉再说别的。

**2. 这些上下文对接下来要做的事无关吗？** 本会话里的一切（探查、决策、走过的死路）都可以扔？那就 **`/clear`**。这是全盘最便宜的一步：不花时间，还把整个窗口还给你。`/clear` 也不是终局：旧会话仍然可以恢复。

这一步搞错的代价是单向的。清掉*相关*的上下文，你就丢了当初为什么这么做的那个**为什么**，再怎么回头读 diff 也补不回来。

**3. 你需要交接出去吗？** `/handoff` 的适用面很窄。只有当你属于下面这些情况时才需要它：

- 换到**新宿主环境**（Claude → Codex），
- 搬到**新目录**或新仓库，
- 把活交给**同事**，
- 或者在**阶段中途**分叉出一个支线任务、又不把手上正在做的事带偏。

那张清单就是全部条件。`/handoff` 买到的是**可携带性**：一份能跟着走人的文件。如果没有东西要跟着走，你就不需要它。

**4. 这活能无人值守地做吗？** 它的边界收得够紧，紧到你离开键盘、不给任何指引它也能跑？那就把它交给**子智能体**，本会话原封不动。自动化评审是标准例子：智能体读 diff 出报告，这过程里不需要你。

**5. 都不符合，就 `/compact`。** 上下文相关、同一个宿主环境、同一个目录，而且你得留在环路里：判定树就落在这里，而且经常落在这里。给它一句指令（`/compact we're going to QA this area`），好让摘要留住下一阶段要用的东西。

`/compact` 是**默认选项，不是第一反应**。它之所以排在最底下，是因为上面那四个问题要么更便宜、要么更精确。人们一上来就用它的失败模式，是一个新会话对某个被摘要压平的决策自信地做错。

## 一手来源与二手来源

除了**继续**之外的每一步，都在把**一手来源**变成**二手来源**：真实发生过的那个会话，被它的摘要顶替。这笔交易形状永远一样：

| 来源 | 信息 | 噪声 | 回旋余地 |
| --------------------------------- | ----------- | ----- | ------------ |
| 一手（继续） | 全须全尾 | 多 | 小 |
| 二手（`/compact`、`/handoff`） | 有损耗 | 少 | 大 |

这就是为什么问题 1 排在最前。只有当留下来的代价超过它省下的东西时，你才去付那份损耗。

## 这些是判断题

这些不是客观题：每一问里都有口味成分，同一个边界，隔两天可能给出两个不同的答案。价值在于**按顺序**问它们，而且要在边界上问，不是在活干到一半时问。
