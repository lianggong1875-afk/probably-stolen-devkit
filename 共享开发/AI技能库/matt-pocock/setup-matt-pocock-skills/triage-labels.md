# 分诊标签

各技能都按五个标准分诊角色来表述。本文件把这些角色映射到本仓库工单系统实际使用的标签字符串。

| mattpocock/skills 里的标签 | 本仓库工单系统里的标签 | 含义                       |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估该工单       |
| `needs-info`               | `needs-info`         | 等待报告者补充更多信息     |
| `ready-for-agent`          | `ready-for-agent`    | 规格已完全定下，可交无人值守智能体 |
| `ready-for-human`          | `ready-for-human`    | 需要人来实现               |
| `wontfix`                  | `wontfix`            | 不会处理                   |

技能提到某个角色时（例如“打上可无人值守的分诊标签”），用本表里对应的标签字符串。

把“本仓库工单系统里的标签”这一列改成你实际在用的词表。
