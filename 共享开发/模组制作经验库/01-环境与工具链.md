## Windows 本机环境两个硬坑

1. **`.ps1` 脚本必须 UTF-8 with BOM**：Windows PowerShell 5.1 读无 BOM UTF-8 会按 GBK 解码导致中文注释炸语法或吞掉 `$PSScriptRoot`。写完 `.ps1` 立即补 BOM；相反，**JSON 必须无 BOM**（Node 不剥 BOM）。
2. **Low Integrity 目录脚本报错**：如果新建目录里的 `.ps1` 报 `not digitally signed`，用 `icacls` 补当前用户权限并将完整性调回 Medium。

## 游戏启停

- 启动只走 Steam：`Start-Process 'steam://rungameid/4348910'`（不带命令行参数，否则弹 Steam 确认框卡住）。
- 退出走 `python 工具库\probes\ps-modbridge\quit_game.py` 或 `CloseMainWindow()`，不要强杀以防丢档。

## 工坊模组蒸馏工具链（2026-11 新增，详见 [19](19-工坊模组逆向与蒸馏.md)）

```powershell
# 0. 若 WorkshopUploader 是首次编译：输出目录要补原生库
#    copy Managed\..\Plugins\x86_64\steam_api64.dll 到 bin\Release\net10.0\
#    并写 steam_appid.txt（内容 4348910）

# 1. 抓工坊全量列表（trend/mostrecent/toprated × 10 页 → 缓存文件夹\workshop-scan\items.md）
D:\0TavernWeave\tools\python314\python.exe .\工具库\workshop-tools\fetch_workshop.py list --pages 10

# 2. 批量导出候选的「名称 + 简介」用于人工筛选（用户要求：先读名字与简介再订阅）
... .\工具库\workshop-tools\fetch_workshop.py brief --ids-file 候选.txt --chars 620

# 3. 订阅 + 下载（复用本机已登录的 Steam 会话；@ 后跟清单文件）
.\工具库\build\WorkshopUploader\bin\Release\net10.0\WorkshopUploader.exe --fetch "@候选.txt"
... --list-subs        # 核对订阅与本地安装状态
... --unsub "@候选.txt" # 蒸馏完退订，别让订阅列表堆积

# 4. 批量反编译 + 架构透视（产物落 缓存文件夹\decomp_ws\<id>\ 与 _reports\<id>.txt）
... .\工具库\workshop-tools\distill_prep.py --ids-file 候选.txt

# 5. 跨模组冲突扫描（我们自己的源码 vs 已装模组反编译目录；退出码 2=ERROR/3=WARN）
... .\工具库\workshop-tools\conflict_scan.py --dir 深空电玩\src --dir "深空当铺：可能是群友\src" --dir 缓存文件夹\decomp_ws --out 缓存文件夹\conflict-report.md
```

**注意**：
- 反编译产物（`缓存文件夹\decomp_ws\`，两批 45 个模组约 17 MB / 3000 个 .cs）**用完即清**，只保留 `workshop-distill\` 里的蒸馏档案。
- 本机 Steam 客户端当前订阅数 = 原有 46 + 蒸馏新增（`缓存文件夹\workshop-scan\subscribed-for-distill.txt` 记录了 45 个），收尾时按该清单退订。
