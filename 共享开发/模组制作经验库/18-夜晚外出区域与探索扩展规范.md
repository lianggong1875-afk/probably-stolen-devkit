# 夜晚外出区域与探索扩展规范

本文档由原版 `AfterhourLocation` / `MapUIManager` / `TransitUI` / `AfterhourEvents` / `ModHelper` 源码，以及工坊标杆模组《樱咲羽衣 · 下层区诊所》（`3844162371`，`SakurazakiUi.dll`，零能力）、《食品券扩展与增强》（`3840817561`）、《Pen 的便利性优化》（`3829957165`）反编译蒸馏而成，专门指导如何在打烊后（`StoreState.CLOSED`）扩展新的夜晚外出地点、商店/谈判摊位、剧情打工 CG 场景、或给已有夜晚地点追加事件与界面。

---

## 1. 四大扩展范式选型

先按玩法决定走哪条路，优先用官方一等接口，不轻易写 Harmony 补丁：

| 范式 | 代表实现 | 适用场景 | 核心做法 |
| --- | --- | --- | --- |
| **A. 极简代理菜单型** | 原版 `CommissaryLocation` / `DumpingGroundLocation` | 有一个立绘/背景图 + 右侧一列按钮/数值提示（如翻找、兑换、触发交互） | 调 `ModHelper.AddAfterhourLocation(...)`；背景走 `BackgroundKey = "modId:bg"`，按钮走 `buildPanel(CustomUIBuilder)`，原版自动补标题与「返回」按钮 |
| **B. 夜晚商店 / 谈判摊位型** | 原版 `DrJacksonLocation` | 像博士一样带货去卖、从对方摊位挑货讲价购买、离开时带走未清货 | 继承 `AfterhourLocation`（或配 `DelegateAfterhourLocation`），设 `ShowsStoreCounters = true` 并覆写 `GetFrontCounterPosition` / `GetBackCounterPosition`；`Arrive` 放货+激活外部顾客，`Leave` **先抢救玩家自有物品再清台** |
| **C. 全屏 CG / 视觉小说打工型** | 《樱咲羽衣 · 下层区诊所》 `ClinicVolunteer` + `ClinicNightView` | 不带夜晚背包，全屏展示室内底图与事件插画 CG、底部打字机旁白/跳过、回店结算回礼 | 继承 `AfterhourLocation`，设 `UsesAfterhourBag = false`；提供 `StageObject` 自管 `SpriteRenderer`（按相机视口 `Aspect Fill/Fit`），`BuildPanel` 隐藏原版默认按钮并接管成底部对话框，回店后在 `OnAfterhourLeaveLate` 发奖 |
| **D. 扩展已有夜晚地点与事件** | `VanillaAfterhourEvents`、`CommissaryExpansion`、`Pen_mod_QoL_Tweaks` | 给废料场/配给站/博士或新地点加随机/星期几事件、封店、卡片信息、扩展商店目录 | 用 `ModHelper.AddAfterhourEvent(...)` 挂事件与 `GetAfterhourModifier`；想往地图站台卡片下方塞自定义提示/图标格时，Postfix `TransitUI.BuildEventList(RectTransform, AfterhourLocation, float)` 往返回 `ScrollRect.content` 追加节点 |

## 2. 原版官方接口全景表

### 2.1 `ModHelper` 夜晚外出 API（零能力可用）

| API | 作用与要点 |
| --- | --- |
| `AddAfterhourLocation(modId, id, title, onArrive, onLeave, buildPanel, imageKey, backgroundKey, ambienceId, isDiscovered, isAvailable)` | 快速注册 `DelegateAfterhourLocation`；支持链式再补 `showsStoreCounters`、`usesAfterhourBag`、`frontCounterPosition`、`backCounterPosition`、`onTick`、`leaveWarning`、`maxConcurrentEvents` |
| `AddAfterhourLocation(AfterhourLocation location)` | 注册自定义 `AfterhourLocation` 子类（同 `Id` 会覆盖，方便热重载） |
| `RemoveAfterhourLocations(modId)` | 卸载/停用时按 `Source == modId` 清理（建议先在当前位置时调 `Return()`） |
| `GetCurrentAfterhourLocationId()` / `IsOutsideStore()` | 查当前所在夜晚地点 Id 与是否在店外 |
| `ReturnFromAfterhour(askAboutGroundItems = true)` | 返回店铺；传 `true` 时若 `afterhourInventory` 还有物品会弹出原版提示 |
| `RegisterAfterhourAmbience(modId, id, soundKey)` | 在 `OnModAssetsLoaded` 之后，把 `mod.Sounds[soundKey]` 注册给 `StoreSoundPlayer` 作夜晚环境音 |
| `GetAfterhourVisits(locationId)` / `GetAfterhourCounter` / `SetAfterhourCounter` | 读写原版按地点保存在存档里的 `AfterhourLocationState`（含 `visits`、`lastVisitDay`、`counters`） |
| `AddAfterhourEvent(...)` / `RemoveAfterhourEvents(modId)` | 注册定时/概率夜晚地图事件；支持 `weekdays`（按 `dayCounter % 7`）、`dailyChancePercent`、`closesLocation`、`AfterhourEffect(text, modifierKey, value, polarity)` |
| `StartAfterhourEvent` / `EndAfterhourEvent` / `IsAfterhourEventActive` / `GetAfterhourModifier` | 代码主动启停事件或读取当前地点叠加后的事件数值修正 |

### 2.2 `ModHook` 夜晚生命周期事件与调用顺序

- **出发**：`MapUIManager.Travel(location)` 黑屏转场中依次执行：
  1. `OnAfterhourArriveEarly(location.Id)`
  2. `OnGoingOutside(location)`（关纸张/物品弹窗、切 `EmporiumEntry.OnLeaveStore()`；若 `UsesAfterhourBag == true` 则显示外出背包并把店主背包物转入 `afterhourInventory`；记 `wentToAfterhoursLastNight = true`、`lastAfterhourOutingDay = dayCounter`）
  3. `ShowStage(location)`（优先激活 `location.StageObject`；否则用内建 `AfterhourStage` 加载 `BackgroundKey`）
  4. `location.Arrive()` → `OpenLocationPanel(location)`（优先激活 `PanelObject`；否则建 `"afterhour_location"` 窗口并调 `location.BuildPanel(builder)`）
  5. `afterhourState.visits++`；播放 `AmbienceId` 环境音；触发 `OnAfterhourArriveLate(location.Id)`
- **驻留帧回调**：`MapUIManager.Update()` 每帧调用 `Current.Tick()`（已包外层 `try/catch` 打 `LogError`）。
- **返回**：`MapUIManager.Return()` 若 `afterhourInventory` 非空且未禁用外出包，会先弹 `GetLeaveWarning()` 确认框，确认后进 `ReturnNow()`：
  1. `OnAfterhourLeaveEarly(location.Id)`
  2. `CloseLocationPanel()` → `location.Leave()` → `HideStage()`
  3. `OnReturning()`（`Current = null`、`OnArriveStore()`、若用外出包则将物品转回店里、`RestoreStoreUIAfterReturn()`）
  4. `OnAfterhourLeaveLate(location.Id)`（**最适合在此处发夜间帮工/探险回店奖励**）

### 2.3 零能力读写扩展文本与无污染存档（樱咲羽衣模式）

即使 `<Capabilities />` 为空（零权限），原版也开放了两套官方白名单通道：
- **读取模组随包文本**：`ModHelper.ReadModFileText(modId, "Dialogue/night.zh-CN.txt")` 与 `ModHelper.ModFileExists(modId, relPath)` —— 内置路径越界校验，不触发 `files` 能力扫描，适合外置 `.txt` / `.json` 多语言台词表（配合 `LocHelper.GetCurrentLocaleCode()` 区分 `zh-CN` / `en-US` / `ja-JP`）。
- **按模组隔离的存档字典**：`ModHelper.GetModData` / `SetModData` / `GetModDataInt` / `SetModDataInt`（底层读写 `PlayerStore.Instance.ModData()`），不污染原版数据结构，也无需手写 `ES3Type` 或 patch `SaveGame`（复杂状态可用紧凑管道符或版本头字符串编码进单个 key，读出校验版本号与边界）。

## 3. 美术资源与画面排版规格

### 3.1 四类常见美术资产规格（实测基准）

| 资产用途 | 推荐分辨率与比例 | 存放目录 | 关键配置与原理 |
| --- | --- | --- | --- |
| **地图站台卡片缩略图** (`ImageKey`) | `16:9` 横图（如 `1672×941` 或 `1280×720`） | `Textures/<key>.png` 并在代码注册进 `mod.Sprites` | `TransitUI` 卡片槽为 `296×168`（`16:9`），自动 Aspect Fill 居中裁剪；**可与全屏底图共用同一张图** |
| **夜晚全屏背景底图** (`room` / `BackgroundKey`) | `16:9` 高清插画（如 `1672×941`） | `Textures/<key>.png` | 插画用 `FilterMode.Bilinear` + `Clamp`；像素风场景则走纯内存 `mip 0` 重建 + `FilterMode.Point` |
| **夜晚剧情 / 打工 CG** (`illustration`) | `16:9` 高清插画（如 `1672×941`） | `Textures/<key>.png` | `sortingOrder = 22` 盖在 `room`（`20`）之上；显示 CG 时把 `room.color` 设为 `Color.black` 当作宽屏黑边底板 |
| **关联角色立绘与换装差分** | `~1466×1073`（与美化包 `1470×1070` 同档） | `Textures/`（`EnsureCrispPortraitTexture` 去 Mipmap）或 `Textures/Items/` | 像素风必须走 `FilterMode.Point` + 无 Mipmap；`ppu` 按身高对齐原版（美化包基准 `tex.height / 1.54f`，樱咲羽衣用 `rect.height * 100f / 175f`，`pivot ≈ (0.5f, 0.657f)` 或 `(0.5f, 136f/175f)`） |

### 3.2 为什么 `ImageKey` / `BackgroundKey` 老是显示 `"IMAGE PLACEHOLDER"`

原版 `TransitUI.ResolveImage` 和 `MapUIManager.ResolveBackground` 内部走的都是 `CustomUIManager.Instance.GetSprite(key)`，而 `GetSprite` 有两条死规定：
1. **不带 `modId:` 前缀的裸键名根本不会查任何模组的字典**，必须写成 `"<modId>:<spriteKey>"`（如 `"sakurazaki_ui_clinic:ui_clinic_room_v1"`）。
2. **`GetModSprite` 只查 `loadedMod.Sprites` 和 `loadedMod.PaperSprites`，绝不查 `loadedMod.Textures`**！凡放在 `Textures/` 根目录的大背景图，引擎冷启动只放进 `mod.Textures`，因此在 `OnModAssetsLoaded` 里必须显式：
   ```csharp
   if (mod.Textures.TryGetValue(key, out Texture2D tex) && tex != null) {
       tex.wrapMode = TextureWrapMode.Clamp;
       tex.filterMode = FilterMode.Bilinear; // 像素风背景则先 mip0 重建后设 Point
       Sprite sp = Sprite.Create(tex, new Rect(0, 0, tex.width, tex.height), new Vector2(0.5f, 0.5f), 100f);
       sp.name = key;
       mod.Sprites[key] = sp;
   }
   ```

### 3.3 全屏舞台 `StageObject` 的相机自适应写法

原版 `AfterhourStage` 只负责把 `BackgroundKey` 塞给一个固定 `scale=(1,1,1)` 的 `SpriteRenderer`，高分图按 `ppu=100` 会严重溢出或留黑边。想要不同分辨率/比例（16:9 / 16:10 / 21:9）都严丝合缝，推荐参考 `ClinicNightView.FitStage()` 自己持有一个 `StageObject`（含 `room` order 20 与可选 `cg` order 22），并在 `Tick()` 中按主摄像机视口自适应：

```csharp
Camera cam = Camera.main;
if (cam == null || !cam.orthographic) return;
float viewH = cam.orthographicSize * 2f;
float viewW = viewH * cam.aspect;
Vector3 pos = new Vector3(cam.transform.position.x, cam.transform.position.y, 0f);
// 背景底图：Aspect Fill（铺满全屏不留黑边）
Vector3 roomSize = room.sprite.bounds.size;
float fill = Mathf.Max(viewW / roomSize.x, viewH / roomSize.y);
room.transform.localScale = new Vector3(fill, fill, 1f);
room.transform.position = pos;
// 剧情 CG：Aspect Fit（完整居中不裁切）
if (cg != null && cg.sprite != null) {
    Bounds b = cg.sprite.bounds;
    float fit = Mathf.Min(viewW / b.size.x, viewH / b.size.y);
    cg.transform.localScale = new Vector3(fit, fit, 1f);
    cg.transform.position = pos - b.center * fit;
}
```

## 4. 关键实现规范与避坑清单

1. **夜晚商店（`ShowsStoreCounters = true`）离开前必须先救出玩家物品**（对标 `DrJacksonLocation.Leave`）：
   - 原版在夜晚商店离开时会调用 `EmporiumEntry.Instance.ResetFrontCounterGrid()`、`ClearFrontInv()`、`ClearBackInv()`，**它们会销毁台面上残留的所有物品**！
   - 若玩家把自己的材料/待售品摆上了谈判台或柜台，必须在 `ClearFrontInv`/`ClearBackInv` **之前**遍历 `frontInvinvElement` 和 `backInvinvElement`，把 `GeneralHelper.IsItemOwned(item)` 的物品 `CloseContentWindow(true)` + `Expel` 暂存到列表，清台并 `TransferCounterToBackInv()` 之后，再用 `GraphUtils.EmporiumTryAdd(EmporiumEntry.Instance.backInvWindow, item)` 塞回店铺后仓（同时把 `afterhourInventory` 里的物品也救回）。
2. **纯剧情/打工地点务必关闭外出背包**：
   - 覆写 `UsesAfterhourBag => false`（或在 `DelegateAfterhourLocation` 上设 `usesAfterhourBag = false`），避免底部弹出大背包遮挡视觉小说对话框。
3. **自建全屏面板时清理原版弹窗壳子的布局与遮罩**：
   - `BuildPanel(CustomUIBuilder native)` 拿到的是原版 `afterhour_location` 窗口壳子：如果自己挂全屏 `surface` 排版，需禁用原版根节点上的 `LayoutGroup` / `ContentSizeFitter` / `Graphic` / `Mask` / `RectMask2D` 并隐藏其余原生子节点，同时调 `native.SetCloseOnEscape(false).SetDraggable(false).OnClose(onReturn)`，保证按右上角关闭或触发离开时能正常走 `MapUIManager.Instance.Return()`。
4. **回店发奖必须在店内安全态下幂等投递**：
   - 不要在 `Leave()` 回调里直接往 `backInvinvElement` 塞东西（此时 `OnReturning()` 还没把店铺库存切回来）！
   - 应在存档中先记一笔待发数量/物品清单，在 **`ModHook.OnAfterhourLeaveLate` + `ModHook.OnGameLoadedLate` + `ModHook.OnWakingUpLate`** 三处统一调投递函数，先校验 `PlayerStore.Instance.playerLocation == PlayerStore.PlayerLocation.IN_STORE`，用 `EmporiumEntry.Instance.backInvinvElement` 放前后的数量差（或 `item.parentInventory == targetInv` 引用比对）确认真正入库后再扣减待发计数。
5. **`IsAvailable()` 门禁要守住原版前提**：
   - 自己覆写 `IsAvailable()` 时，除判断本模组每日次数/冷却外，务必保留 `base.IsAvailable()`（检查地图闭店事件 `IsClosedByEvent()`）、`PlayerStore.Instance.storeState == PlayerStore.StoreState.CLOSED` 与 `PlayerStore.Instance.visitLeftTonight > 0`。
6. **在已有地图卡片上追加提示信息**：
   - 若只想在废料场/配给站/博士的地图卡片下加几行状态或小图标预览，不要整张重画，直接 Postfix `TransitUI.BuildEventList(RectTransform, AfterhourLocation, float)` 拿返回的 `ScrollRect`，向 `scroll.content` 添加带 `LayoutElement`（设 `minHeight`/`preferredHeight`）的 `TextMeshProUGUI` 或 `GridLayoutGroup`（注意 `raycastTarget = false`，免得挡住卡片点击选中）。
