### 3.1 「如果真是 LLM」的延迟与失败 —— 它其实已经答了

**没有 LLM，但作者在七处处理了同一个问题：实时游戏里等一个不保证按时到来的结果。** 下面七段是我们做生成内容时的直接参照物。

#### ① 分帧预算：3 ms/帧 + 每帧最多 3 件（[AiStockIndex.cs:239](缓存文件夹/decomp_ws/3832941698/AiEmporium/AiStockIndex.cs#L239)）

客人货单要现场"造"（`DirectoryMaster.Item(id)` 是重活）。做成协程 + 硬预算：

```csharp
private static IEnumerator Deliver(Visit visit)
{
    Stopwatch frameWork = Stopwatch.StartNew();
    foreach (string item in list) {
        if (...候选...) remaining.Add(item);
        if (frameWork.Elapsed.TotalMilliseconds >= 3.0) {   // 3 ms 一到就交还一帧
            yield return null;
            if (!IsCurrent(visit.Client)) yield break;      // 客人走了 → 立刻中止
            frameWork.Restart();

    }
    ...
    if (placed - placedAtFrameStart >= 3 || frameWork.Elapsed.TotalMilliseconds >= 3.0) {

    }
}
```

#### ② 预算不是猜的，是**学出来的**（[AiStockIndex.cs:320](缓存文件夹/decomp_ws/3832941698/AiEmporium/AiStockIndex.cs#L320)、[392](缓存文件夹/decomp_ws/3832941698/AiEmporium/AiStockIndex.cs#L392)）

```csharp
private const double FrameBudgetMs = 3.0;
private static ConditionalWeakTable<Func<GameItem>, FactoryCost> factoryCosts = new(); // 以"工厂委托"为键记耗时
double num = factoryCosts.TryGetValue(factory, out var value) ? value.Milliseconds : 1.5; // 没测过按 1.5ms 估
if (frameWork.Elapsed.TotalMilliseconds + num > 3.0) { yield return null; ... }

double totalMilliseconds = slice.Elapsed.TotalMilliseconds;                      // 实测这一件的真耗时
```

先估、超了就等、等完记下来——第 N 帧之后它就知道"这个物品工厂要 8 ms，下帧开头别碰它"。这是"不靠帧率赌运气"的唯一稳做法。

## 4. 踩坑与红线

1. **单文件吃 30.1%**（`DeepSeekConstruction.cs` 14,539 行）：建造 UI、设施面板、剧情播放、存档迁移、反射助手全混在一个 `static class`。比 `深空诊所`(54.6%) 好一点，但同样是"下次改动必踩雷"。**建议给 `Invoke-PreMergeGate.ps1` 加一条按文件行数报警（单文件 >2,500 行即拦）。**
2. **给 ModLoader 自己的 UI 打 6+ 个补丁**（`ModConfigWindow.BuildEntry/Open/Apply/WriteWidget/ResetWidgets` + `ModElement.Init` + `ModUIManager.ShowMod`），只为在配置面板放一个数字滑条。**全档案最不该抄的部分**：加载器升级即全废，还要跟所有改配置面板的模组抢同一个 Postfix。要做数字输入就走 `ModHelper`/`ModConfig` 公开面或自己的窗口。
3. **没有 `HotReloadPrepare/Activate`**（0 处），却满屏静态引用——`static Sprite[] frames = new Sprite[88]`、`static Dictionary<string,Sprite> sprites`、`static RectTransform backdrop`。热重载一次就会拿到已销毁的 Unity 对象；它只做到"`OnDisable` 里逐项清"，按我们规范**必须成对写 `HotReloadPrepare/Activate`**。
4. **立绘首帧不分帧**：`PortraitDeltaBank.Get` 在**主线程**一次解 88 张 PNG（由 `StoreClientMono.Update` 的 Postfix 触发）。作者明明写了 `PortraitPng.DecodeIncremental`，却只用在建造预览（[DeepSeekPreviewRender.cs:135](缓存文件夹/decomp_ws/3832941698/AiEmporium/DeepSeekPreviewRender.cs#L135)）——同一作者两套预算策略，标准有了没贯彻。做立绘务必把首帧拆开。
5. **5 处 Transpiler**（`HopperHelper.Passes/IsAway`、`PlayerStore.FindAllItem`）：手法很干净（`Calls(原版方法)` → 换 operand 成同名扩容器，扩容器内部再调原版），但按我们红线**能 Prefix/Postfix 就不写 IL**；且原版签名一变就**静默失效**——玩家只会发现"东西送不进家里"。
6. **空 `catch {}` 吞异常**：[AiLoc.cs:39](缓存文件夹/decomp_ws/3832941698/AiEmporium/AiLoc.cs#L39) 把整段本地化读取包在 `try { ... } catch { }`；`AiClientFactory.CanModifyGuns` 两处 `catch {}`。违反"对内暴露"硬规范。
7. **自检代码留在出货里且不可达**：`DeepSeekChecks.Run/ColdStart` 是 `public static`，却没注册任何调试入口（`AddDebugFunction` 只 2 处，是重置访问/发名片）。每次发行都背着 432 行跑不到的代码——要么挂到 `AddDebugFunction`，要么删。
8. **549 项硬编码标签表 = 兼容性坑**：`AiStockCatalog` 把物品 id→标签冻结在编译期，**别的模组新加的物品不在表里 → 无法被 AI 常客收购**（`Matches()` 查不到直接 `false`）。我们要做"可被某类顾客收购"的品类，必须查活体 `item.IsTag()` 或提供注册接口。
9. **电话号硬编码 + 保留号黑名单**：`DefaultNumbers` 15 个固定号，撞号时 `FindFreeNumber` 往后找，还硬写死 6 个原版占用的号（`8376/8815/56371/4615/3319/51189`，[AiPhones.cs:153](缓存文件夹/decomp_ws/3832941698/AiEmporium/AiPhones.cs#L153)）。**这张黑名单不可维护**——原版加一个联系人就会撞。稳妥做法是"号码从高位段随机 + 落盘记住"。
10. **`PlayerStore.Instance` 未判 `HasInstance`**：`AiScheduler.OnGenerateCustomer` 第一行 `if (manager == null || PlayerStore.Instance == null)`（[AiScheduler.cs:49](缓存文件夹/decomp_ws/3832941698/AiEmporium/AiScheduler.cs#L49)）——`Instance` 是 getter，取完再判 null 已经晚了。同类写法在 `AiClientFactory.CanModifyGuns`、`AiCards.Give` 反复出现（靠 try/catch 兜着才没炸）。
11. **`.csproj` 是反编译产物**：`TargetFramework=netstandard2.1`、`LangVersion=14.0`、`AllowUnsafeBlocks=True`——**别照抄**。我们固定 `net472` / C# 9 / Unity 2021.3.45f2。
12. **我们的红线复述**：它踩了 ②异常策略（空 catch）、③Harmony 纪律（给加载器 UI 打补丁、无热重载钩子）；持久化这条它做得比我们好；**没踩**：零能力（`<Capabilities/>` 空且无 `File.*`/网络）、真伪判定（全篇不碰 `realCondition`/`fakeCondition`）。
