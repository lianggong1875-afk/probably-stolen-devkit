## 一、Locale Error Fix：文字表加载时序

### 1. 症状

日志里刷：

```
Exception: Attempting to use an invalid operation handle
```

之后凡是读文字的地方都重复报同一句，名称显示成 `liquid_water` 这类 key。

### 2. 根因

游戏文本用 Unity Localization（`LocalizationSettings.StringDatabase`），**文字是进游戏后才逐步加载的**。有的模组在自己的 `Init/OnEnable`（`ModLoader.Awake` 阶段）就去 `LocHelper.Get(table, key)`，此时 Localization 还没初始化完 → 底层抛 `invalid operation handle`，且这个错误状态会留到进程结束。

### 3. 修法：Patch 掉文字读取入口，失败时降级成 key

```csharp
[HarmonyPatch(typeof(LocHelper), "Get")]
internal static class PatchLocHelperGet
{
    private static bool Prefix(string table, string key, object[] arguments, ref string __result)
    {
        __result = key;                                  // 默认降级：显示 key 本身
        string text = null;
        try {
            text = (arguments != null && arguments.Length != 0)
                ? LocalizationSettings.StringDatabase.GetLocalizedString(table, key, arguments, null, FallbackBehavior.UseFallback)
                : LocalizationSettings.StringDatabase.GetLocalizedString(table, key, null, FallbackBehavior.UseFallback, Array.Empty<object>());
        } catch (Exception ex) { WarnOnce(table, key, ex.Message); }

        if (text != null) { __result = text; return false; }

        // 二次尝试：直接拿 StringTable 的 entry（绕过 handle 机制）
        try {
            StringTable t = LocalizationSettings.StringDatabase.GetTable(table, null);
            string v = t?.GetEntry(key)?.Value;
            if (v != null) __result = v;
        } catch (Exception ex) { WarnOnce(table, key, ex.Message); }

        return false;                                    // 永不调用原版（原版就是抛异常的那条路）
    }
}
```

配套还 Patch 了 `LocHelper.HasEntry`（同样降级），并有 `PatchLocHelperHasEntry.cs`。

## 二、CJK Font Fallback：汉字显示成空白

### 1. 根因

游戏 UI 用 TextMeshPro，每个 `TMP_FontAsset` 只含自己烘焙过的字形。原版给中文翻译准备了 CJK 字体，但**大多数 UI 字体没有把 CJK 字体列进自己的回退链**，于是任何 CJK 字符（包括**模组名、模组设置项**）渲染成空白。

### 2. 修法：往 TMP 全局回退表里加字体（0 个 Patch）

```csharp
public static int Apply(ModLog log)
{
    List<TMP_FontAsset> fallbacks = TMP_Settings.fallbackFontAssets;   // ← 全局回退表
    if (fallbacks == null) { log.Warning("TMP_Settings has no global fallback list"); return 0; }
    var added = new List<string>();
    foreach (var c in FindCandidates())            // 已加载字体里挑覆盖率最高的
        if (!fallbacks.Contains(c.Font)) { fallbacks.Add(c.Font); added.Add($"{c.Font.name} ({c.Covered})"); }
    if (added.Count > 0) { log.Log("Added global fallbacks: " + string.Join(", ", added)); RefreshVisibleText(); }
    return added.Count;
}

static IEnumerable<Candidate> FindCandidates() =>
    from f in Resources.FindObjectsOfTypeAll<TMP_FontAsset>()
    where f != null && f.material != null                 // 有材质的才是真加载
    let rank = RankOf(f.name)
    let covered = Scripts.Sum(s => Coverage(f, s.Value))  // 用样本字串测覆盖率
    where covered > 0
    orderby rank, covered descending
    select new Candidate { Font = f, Rank = rank, Covered = covered };

// 覆盖率：atlasPopulationMode == Dynamic(1) 时用 HasCharacter(c, false, true)
static int Coverage(TMP_FontAsset font, string sample)
{
    bool dynamic = (int)font.atlasPopulationMode == 1;
    int n = 0; foreach (char c in sample) if (font.HasCharacter(c, false, dynamic)) n++;
    return n;
}

static void RefreshVisibleText()
{
    foreach (var t in Resources.FindObjectsOfTypeAll<TMP_Text>())
        if (t != null && t.isActiveAndEnabled) t.ForceMeshUpdate(false, false);   // 强制重排版
}
```

样本字串与优先级（很实用的小技巧）：

```csharp
Scripts = { {"zh","的是语言模组传奇沙理雨雾魔"}, {"ja","あいうアイウ"}, {"ko","한국어글"} }
Preferred = { "NotoSans", "SourceHan", "wght", "Lubrifont", "Gugi", "YeonSung", "YujiBoku", "MaShanZheng" }
// 名字命中越靠前 rank 越小；都不命中给中性 rank（等于"装饰性手写体"级别）
```

### 3. 要点

- 只加"全局回退"（`TMP_Settings.fallbackFontAssets`）就够，不必挨个改每个 Text 的字体。
- 加完**必须刷新可见文本**（`ForceMeshUpdate`），否则当前屏幕上的字不会立刻变。
- 装饰体（手写/毛笔）排在无衬线后面，只在别的字体都没有该字时才用。

## 四、对我们的用法

1. **模组文案/物品名要显示中文**：依赖游戏自带 CJK 字体 + 全局回退；如果我们的模组用了自己的字体资源，记得自己也往 `fallbackFontAssets` 里加一份，或至少不要把字体设死。
2. **我们自己写 `LocHelper.Get` 调用时**：不要在 `Init/OnEnable`（启动早期）读文字并缓存到静态字段——那时可能没就绪。要么在 `OnGameLoadedLate` 之后再读，要么监听 `SelectedLocaleChanged` 重读。
3. **遇到名称显示成 key（如 `liquid_water`）**：先确认是不是时序问题，再查 table/key 是否真存在。
4. 我们如果要做"多语言 UI"，用 `Func<string>` 延迟求值（参考 Wild's Network 的 `tabLabel`），避免启动期固化。

## 五、待验证 / 风险

- Locale Error Fix 的做法是**完全接管 `LocHelper.Get`**：如果别的模组也 Patch `LocHelper.Get`（例如做词条注入），两者会互相覆盖，谁后跑谁生效。我们要做类似事时应使用 `HarmonyAfter`/`Prefix 返回 true` 的宽松写法。
- 它 `return false` 永不执行原版，等于放弃了原版的任何额外处理（如 fallback locale 链）。真机上可能表现为"某些语言下本应回退到英文，却显示 key"。
