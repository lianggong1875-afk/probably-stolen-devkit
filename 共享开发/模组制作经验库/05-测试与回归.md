# 05 测试与回归

## 原则：只写测真实行为的真测试

- **严禁**写 `Contains(源码, "具体变量名/文件名")` 这种字面量假断言，也不要为离线测试而把生产代码硬拆成一堆 `*Policy.cs` 和 `#if !ARCADE_PURE_POLICY` 条件编译。
- 离线测试统一放在 `<项目>\tests\`，聚焦能离线独立运行的核心不变量与纯逻辑（文案、判定规则、定价公式、采样几何、立绘字节校验等）；涉及 Unity 渲染、UI 交互、Harmony 运行期生效的部分直接走真机验证。

## 运行命令

```powershell
.\工具库\regression\Run-Regression.ps1                # 运行全部真测试
.\工具库\regression\Run-Regression.ps1 -Only appraisal # 只跑单个套件
.\工具库\regression\Run-Regression.ps1 -List           # 列出套件
```

缓存统一写在 `深空电玩\build\regression\<suite>\`，每次跑前自动清理覆盖。

## 离线测试编译说明

引用游戏 `Managed\` 下的 `Assembly-CSharp.dll` 与 `UnityEngine.*.dll` 可脱机加载并 `new` 普通 C# 类，但一旦调到 Unity native 成员（`Texture2D`、`Sprite.Create`、`GameObject`）会抛异常；所以离线测试只覆盖纯逻辑与数据规则，不强行造几十个假替身去模拟引擎。
