# 深空当铺模组制作经验库

**这里放什么**：做《深空当铺》两个模组（`深空电玩` / `深空当铺：可能是群友`）时反复用得上的经验、踩过的坑、硬性规范。开新会话先读这里，不要从零检索。

**这里不放什么**：进度与交接（在各自项目的 `PROGRESS.md`）、历史回执（在 `build/wx-*/RECEIPT.md`）、一次性脚本（用完删）、工具本体（在 `工具库\`）。

## 两个高频入口

- **要动真机**：先 [10](10-开发桥接器能力速查.md) 查桥能不能做，再 [04](04-真机测试与探针.md) 走流程。
- **踩到怪症状**：直接翻 [07](07-踩坑台账.md) 按现象对。
- **桥本身不够用**（缺工具、要改行为）：改 [深空桥接器](../../深空桥接器/README.md) —— 那是桥的本地源码工程，别在玩法项目里写探针绕路。

约定：
- 新经验**先加到对应主题文件**，一句话能说清的就加到 07 的表格里，别只留在对话里。
- 每条经验尽量带**触发条件 + 现象 + 修法 + 验证方式**，只写"要注意 XX"没有用。
- 工作区结构、工具位置这些跟着实际改，改完回来更新 01。
