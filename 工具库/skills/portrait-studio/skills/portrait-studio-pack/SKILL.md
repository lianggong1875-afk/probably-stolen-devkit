为只有图片或需要新工程的作者制作独立静态包。已有换图工程适合 portrait-studio-adapter；动态适配由管理器负责。

先用一句简单的话提示路线：“你是从图片开始制作，适合独立包模板；如果已经有换图模组，就在原工程加接口。”用户已说明情况时直接采用对应路线；情况不清楚时只问“你已经有能换图的模组，还是只有图片？”，无需作者判断技术实现。

如果作者明确愿意依赖管理器、把静态显示和大小位置全部交出去，推荐 portrait-studio-managed。已选定当前路线就直接执行，不反复询问或自动转成托管。

读 [公开协议](references/静态资源公开协议.md) 和 [制作与绑定](references/制作与绑定.md)，按以下步骤完成：

先读 [范例用法](references/范例用法.md)，从自带工程创建新包。普通替换保留已提供的入口、SDK 和构建流程，主要修改资源、清单和构图。工作资料以工具包、作者素材和指定工程为起点；需要确认游戏行为再查指定游戏的公开 API 或程序集，不遍历其他已安装模组来猜实现。只要求诊断测试问题时，先报告原因和工具包缺陷，不改被测工程或成品。

图片默认保留原分辨率，用几何调整显示大小；去背、裁切与缩图分别按作者要求处理。涉及图片转换或性能判断时读 [图片处理与预算](references/图片处理与预算.md)，按实际加载和缓存估算，不用整包图片总和推断超预算，不把换图失败称为加载器拒绝模组。

原版顾客先区分“只换某个职业”与“换所有共用这张图的人”，详见 [职业与图片键](references/原版职业与图片键.md)。职业查 [职业表](references/vanilla-client-roles.tsv)，共用图片查 [图片键表](references/characters.tsv)；已说明就直接采用，不多问。

1. 确认要替换的对象、图片和默认候选。原版人物按上述职业表或图片键表确定身份；人物、通缉照片、场景背景和旅行卡分别处理。自定义对象使用创建者 mod ID 与稳定对象 key。
2. 先看图片和实际显示入口，再确定构图、大小和位置。原图像素宽高不等于固定相框；检查真实裁切、遮挡和布局，不能只按原图宽高推荐裁切、缩小或填满。作者有明确构图就照做；未说明时保留新图完整构图和比例，给出可调整的默认大小与锚点。确需选择时只问“想完整展示人物，还是突出半身？有没有参考效果？”，由 AI 处理具体几何。详见制作与绑定。
3. 审查每个显示位置的全部写图路径。只接固定单图和用户主动选择的静态候选；根、资源组、位置、图片均声明 static。动画、表情和剧情变图保留在接口外，混合模组按位置划分。
4. 用 `python scripts/new_pack.py --output <新源码目录> --id <唯一ID> --name <名称>` 创建工程。修改作者信息和目标游戏版本，替换示例图、删除不用的位置。模板自带独立显示端，无管理器前置。
5. 按制作与绑定文档填写清单、完整纹理几何和 defaultResource。需要调整构图时用 `python scripts/framing.py --source <源码目录>`，见 [构图与显示](references/构图与高清显示.md)；支持拖动、缩放、锚点和同组候选，无需模型识别人脸。保留模板的套装设置、管理器协作与可关闭的去像素化选项；该选项会影响背景等场景画面，向作者说明范围。自定义位置在创建处显式绑定，批量用 BeginBatch/EndBatch；每帧只维护已知对象和 Tick/Resolve。保留按需加载、缓存预算和超限回退。
   作者提供多套图时，在同一清单的 portraitSets 声明套装名与逐目标图片映射，保留模板的“立绘套装”设置；缺图保留当前选择。规则见公开协议“套装声明与切换”，不按图片顺序猜分组。
6. 执行 `python scripts/validate.py <源码目录>`，再用 `python scripts/build.py --game-root <游戏目录> --source <源码目录> --output <不存在的成品目录>` 构建。工程与成品放 Mods 外；python 可替换为本机解释器路径。运行包只带清单、DLL和声明图片。
7. 集中检查独立启停、原图恢复、多候选、通缉赏金和标记、场景几何、自定义身份与剧情。运行游戏、安装和上传按用户授权范围进行；管理器协作需完成协议协商及显示验收。

交付说明只记录：采用的路线、大小位置调整入口、默认图和候选范围、已做检查与待验收项。写当前用法和边界，不附迭代历史或重复免责声明。Schema 见 [清单定义](references/portrait-studio-static-v1.schema.json)，SDK 在 assets/template/SDK。
