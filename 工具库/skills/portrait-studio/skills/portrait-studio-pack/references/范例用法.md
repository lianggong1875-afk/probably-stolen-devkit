# 独立包范例

[完整工程](../assets/template/PortraitPack.csproj)、[入口](../assets/template/Entry.cs)和 SDK 随 skill 提供。用 `scripts/new_pack.py` 复制为自己的新工程，再用 `scripts/build.py` 构建；命令见 [制作与绑定](制作与绑定.md)。不要直接编辑工具包里的范例来制作作者成品。

范例提供导师两张候选、房东、wanted4 照片和 dumping_ground 场景。清单的 defaultResource 决定基础默认图，candidateResources 列出接口候选，portraitSets 把跨目标图片组合成套装。游戏设置的“立绘套装”下拉框可切换立绘1和立绘2；立绘1覆盖全部示例位置，立绘2只替换导师，其他位置保留。修改图片时同步更新哈希、像素尺寸和几何，删除不用的位置。

人物示例保留 576×422 PNG，PPU=200，对应原生参考大小 2.88×2.11；照片为 300×332、PPU=200。新素材按自己的构图校准，不直接沿用范例的固定像素密度。

入口的 OnEnable 只创建驱动，首帧才创建 StaticBridge 和 StaticBindings；停用取消未执行的初始化并释放显示。普通包保留这套生命周期和 SDK，不自行重写读图、目录寻找、消息与缓存。

默认大小位置在 `scripts/framing.py --source <源码目录>` 的本地预览页调整，保存后重新构建；操作与去像素化选项见 [构图与显示](构图与高清显示.md)。保留 `Standalone/HighResolution.cs` 及其工程引用；选项影响背景等场景画面，可关闭。

原生人物、照片和场景由 StaticBindings 绑定。自定义 NPC 在创建者保全原图并创建表面后调用：

```csharp
bindings.BindSprite("npc-main", renderer, trustedOriginal,
    visitId, creatorSurfaceId, visitId);
// Image 使用 BindImage；隐藏由已绑定对象的实际活动状态同步。
// 同一对象换人前解除旧绑定，之后以新 target/visit 重新绑定。
bindings.Unbind(renderer);
```

这里的 bindings 是入口已经创建的同一实例，调用发生在初始化之后。npc-main 须在自己的清单中声明为 custom，subject 使用 NPC 创建者的真实 ID 和稳定 key。创建事件接到原工程，不用全场搜索其他模组的对象。

独立换图验收包括首次加载、首帧前停用、重新启用、原图恢复和换人；管理器协作另验多个候选与让位。编译与清单检查的结果写清，实际显示由游戏验收。

只换原版某个职业时，先读 [职业与图片键](原版职业与图片键.md)。完整 SDK 的 `examples/build_examples.py --occupations` 可生成两套职业范例；本 skill 单独使用时，从自带模板按职业表填写目标与资源组。
