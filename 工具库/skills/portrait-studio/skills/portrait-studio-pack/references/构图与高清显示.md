# 构图与显示

## 调整默认构图

在源码目录准备好图片并更新清单尺寸、哈希后，执行：

Windows 可直接双击 `scripts/启动构图工具.cmd`，选择自己的源码工程文件夹；也可把工程文件夹拖到该文件上。启动器自动寻找 Python 3.10+，未找到时提示安装，无需管理员权限。请保留完整 scripts 文件夹。运行期间保留终端窗口，结束时按 Ctrl+C。

模型或其他系统也可用命令启动：

```text
python scripts/framing.py --source <源码目录>
```

`scripts` 指本 skill 的脚本目录。需要 Python 3.10+ 和现代浏览器，无额外图像库。工具只监听本机，默认半小时结束；`--timeout 7200` 可延长，`--no-browser` 仅打印网址。

选择图片，拖动位置、改变大小，或点击图片设置锚点。参考宽高以游戏场景局部单位填写，人物默认 2.88×2.11 只是原生尺寸参考，不是裁切框。截图可选，直接在浏览器选择作者自己的游戏画面，按实际人物原点与比例校准预览；没有截图时使用示意背景。截图不传给服务器，也不写入包。

“按有效内容估算初始大小”保留图片范围和比例，按透明边界放入参考尺寸并底部对齐。未去背图片按整图处理；头饰、武器、长发也计入边界。作者已经给出构图或合适参数时直接沿用。透明边界用于计算，人物是否自然仍由作者看预览决定，模型多模态能力可选。

同组候选按钮应用当前输入的缩放和位移增量，各图可继续单独校准；不同构图的候选不自动保证脸部对齐。带旧裁切的图片可明确选择“恢复完整图片”，再调整构图。该工具不裁图、去背或重采样，也不强制改变采样方式。

保存写回资源 PPU、pivot 和允许恢复的完整 rect，更新资源版本及其引用，备份留在源码 `.portrait-framing`。清单被其他程序修改时须重新载入，防止覆盖。重新构建后在游戏里验收柜台遮挡、换人及界面布局。预览不会模拟游戏遮罩、相机缩放或 GPU 采样。

## 独立包去像素化选项

零依赖独立模板自带“去像素化（影响场景画面）”选项，默认开启，无需其他模组。它在本包实际显示替换图时暂时关闭游戏的场景像素化组件，背景等场景内容也会变化，可能增加渲染开销。希望保留游戏或其他模组的像素效果时关闭此项。

隐藏或停用后释放控制，末个同模板使用者释放时恢复当前游戏显示设置。游戏原本已关闭该组件时不取得控制。多个模板包通过共享租约协调；其他模组同时修改同一组件的行为需要实际检查。

Portrait Studio 在游戏设置提供「店内去像素化」，默认关闭，开启后影响整个店内画面。独立包按自身设置，在实际显示替换图时请求去像素化，切到原图、让出显示位置或离场时释放。两者共用同一相机控制，最后一方释放时按当前游戏设置恢复。

此功能不增加源图细节，也不提供仅立绘专用的高清层。游戏部分分辨率会先按较低分辨率绘制场景再放大；模板开关改变这一场景处理方式，不修改 PNG 文件。

## 交付检查

以作者期望的完整人物、半身或参考效果校准默认图，抽查不同构图的候选。确认 PNG 原尺寸、清单参数与实际效果一致，检查去像素化选项的场景影响、换人、离场、停用恢复和管理器协作时的实际显示决策。代码检查、预览与游戏显示分别记录实际结果，未运行游戏的项目注明待实机验收。
