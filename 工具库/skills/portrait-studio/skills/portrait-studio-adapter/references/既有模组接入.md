# 既有模组接入

原版职业与共用图片分开声明，填写前读 [职业与图片键](原版职业与图片键.md)，身份见 [职业表](vanilla-client-roles.tsv) 或 [图片键表](characters.tsv)。

接入跟随原工程的真实就绪时机。模组目录登记、存档载入和显示对象创建分别判断；用 `PlayerStore.HasInstance` 确认存在后才读取 Instance，避免在菜单提前创建游戏状态。UI Image 读取有效的 overrideSprite，并让最终写图与还原使用同一通道。只还原仍由自己持有的图片；清理某个显示失败也须继续解绑其他对象和事件，并报告错误。

保留原工程、独立换图、大小位置设置、NPC创建、剧情、语音和交互。先读实际资源/写图/生命周期入口，记录所有会改变同一表面的字典、全局补丁、overlay 和直接赋图。只公开固定静态、能够按表面隔离的位置。

接口接入保持原有构图，不因新图和原图宽高不同而自动裁切、缩小或填满。原图像素宽高不是固定相框；作者要求改变构图时，先检查真实 SpriteRenderer/Image、遮罩、布局和遮挡，再按参考效果处理比例、锚点与位置。裁切、拉伸或重采样须符合作者要求，未经检查不把“溢出”当既定事实。沿用现有配置和调整入口，具体几何换算由 AI 完成。

编入 assets/SDK 的 StaticContract、StaticSession、StaticWire、StaticResources、StaticBridge，参考 assets/AdapterLifecycle.cs。以自己的 mod ID 创建 StaticBridge，注册每个真实表面的 StaticDisplay。sourceDefault 返回作者已经创建的最终静态基础图，geometry 保留原设置；immutableOriginal 来自首次替换前的可信入口。

在首帧或之后的对象创建事件中构造桥和 AdapterLifecycle，游戏在 OnEnable 返回后才登记自身目录。初始化失败清理并记录，不逐帧重试；停用时取消等待初始化的驱动，再解绑已创建的桥。

Show(visitId,original) 报告登场，Hide 报告隐藏；同一对象 displayId 稳定，同一次登场 visitId 稳定，换人更新 target/visit。对象 A→B 先 Hide("rebound")、UnregisterDisplay，再为 B 注册相同 displayId；SDK 递增 epoch，旧事务不会写入 B。清空当前顾客引用时仍保留离场身份到实际隐藏。

每条最终写图路径先读 display.Resolve()；shouldWrite=false 必须完全跳过该表面的赋图与附加层。commit/rollback 的注册回调同步完成且允许失败向上传出；不能把异常吞掉当成功。共享字典或全局副作用无法按表面隔离时，该位置暂不公开 writer；可只公开 resources 供图。其他表面继续按原实现运行。

StaticBridge 自动发布只读活跃位置服务；准确调用 Show/Hide 即可让管理器在会话建立前发现自定义位置，不需暴露组件或依赖管理器。该服务不代替正式显示协商。

root、resourceSet、target、resource 全部明确 static。writer/both 的 target 用 defaultMode=source，resourceSets 可以为空，也可导出多张 PNG 为候选。只供图用 role=resources，不含 targets/revision、不创建桥。资源身份使用创建者 owner 和稳定 key，跨角色须按目标身份另建组。图集导出完整纹理及 rect，保留采样/mip/色彩/边框；不支持的 mesh/分离alpha/特殊材质不公开。

SourceChanged() 用于 defaultMode=source 的原工程主动改变已持有的静态默认图/大小位置，管理器会重新准备但不重抽本次登场。Tick 只维护租约和内存状态；选图接收只存意图，plan/prepare 才检查和加载，commit/rollback/finish 同步无 IO。Disable 按显示解绑再 Dispose，恢复时只还原仍由自己持有的结果。

用 scripts/validate.py 检查资源和清单，沿用作者原工程构建、文件范围与权限扫描；不要套用纯图包白名单删除作者功能。集中检查独立行为、多个 writer 的 silent、各模式布局、多对象、复用/隐藏、租约与失败回滚。交付只列路线、调整入口、范围、检查和待验收事项。
