# 动态立绘接入

作者负责生成动画、表情和服装画面；管理器负责选择来源、候选和位置参数。没有管理器时，作者模组照常运行。此接口也可登记通缉照片、场景和作者创建的 NPC。

## 声明与身份

根目录放 `portrait-studio-dynamic.json`。`format=portrait-studio-dynamic/1`、`contract=dynamic-display-control/1`、`renderMode=dynamic` 必须精确匹配，providerId 等于实际 manifest ID，revision 在声明变化后更新。字段见同目录 Schema 和例子。

每个 target 用 `(kind, subject.owner, subject.key, slot)` 唯一标识：人物 `character/main`、通缉照片 `wanted/photo`、场景 `scene/background`。原版身份 owner=game，binding 分别为 sprite-key、client-role、wanted-key、scene-key；自定义身份 owner=创建者实际 mod ID，binding=custom，binding.key 与 subject.key 一致。client-role 查工具包职业表。仅角色创建者登记其自定义表面，第三方图包不冒名。

候选 id 表示一整套动态效果，例如便装或制服；自动表情和每一帧不拆成候选。候选名称用于列表，运行时原图用于预览；候选启用后，由作者自行加载该套资源。默认候选由 defaultCandidate 指定。独立设置可以调用 `SetStandaloneCandidate`，托管期间只更新恢复后的本地选择。

每份声明上限 1 MiB、512 target、4096 候选，每 target 1～256 候选；ID/名称最多160字符，无控制字符。一个 bridge 同时登记最多32个 display，每个最多16个附加表面。限制仅针对接口登记，动画帧数由作者控制。

## 作者接线

将 `DynamicContract.cs`、`DynamicBridge.cs` 编入作者自己的程序集，不共享 SDK DLL。使用官方 ModHelper 消息、Expose、Lookup，不调用管理器私有方法，不需要管理器前置。原工程已有前置则保留其决定。

在 loader 登记目录后的首帧或实际对象创建时创建一个 DynamicBridge。`RegisterDisplay(targetId, displayId, applyPolicy)` 注册可复用的稳定显示槽。登场时 `Show(visitId, surface, immutableOriginal, layers, originVisitId)`：

- surface 为实际 SpriteRenderer 或 UI Image；不是按对象名搜索出来的替代物。
- immutableOriginal 是替换前保全的可信 Sprite。作者不能修改/销毁它的纹理；动态生成使用自己的纹理。禁止将管理器当前选图当原图。
- layers 包含本套动画拥有的嘴部、遮罩副本等附加显示，不能包含场景公共物体。共享同一表面的不同来源由管理器协调，单 bridge 内不能重复登记。
- visitId 每次人物登场或场景展示变化时更换。同槽重开增加 displayEpoch；换人先 Hide("rebound") 再改变对象归属、再 Show。同一次登场的关联显示可用 originVisitId 关联，缺失时管理器按精确对象协调，不按名字猜。

所有动画 Tick、异步加载完成回调、直接赋图、合成纹理修改、附加层更新之前检查 `display.ShouldWrite`。silent 时跳过这些操作，保留剧情、语音、交互与状态计算。异步结果还须核对当初的 visit/对象是否仍有效，不把旧请求的结果写到新访客上。

`applyPolicy` 同步接收 source 或 silent：

- source：记住 CandidateId 与 Layout，恢复当前剧情状态所需的动画准备。下一次允许写图时显示当前状态，不重建 NPC 或重开剧情。
- silent：同步停止已登记主表面和附加层的写图/纹理修改，隐藏作者自有覆盖层，撤销作者布局包装，随后返回。保留主表面现有画面，交给管理器切换。
- 回调不调用 Show/Hide/注销/再次发控制请求；回调中 ShouldWrite 为 false。初始化、换图和布局失败必须抛错，SDK 会禁止写图，直到重新选择成功或脱管恢复成功。

每帧调用 bridge.Tick，检查 ShouldWrite 也会检查租约。隐藏前调用 Hide；销毁前 Hide("destroyed") 并 UnregisterDisplay；禁用时先停作者循环、Dispose，再清理自己的对象/纹理。Dispose 不让已隐藏的对象重新播放。创建新 bridge 会产生新 instance。

## 布局

layoutOwner 固定 provider。管理器通过接口发送最终 scale/x/y，不再给该表面额外套缩放；全局倍率也由管理器合并进参数一次。作者把它应用在自己的最终构图上，基准是作者默认布局，不能在上次结果上累乘。

scale 范围 0.25～3；x/y 范围 -1～1，分别按默认画布宽/高归一化，正 x 向右、正 y 向上。主图、嘴部和随人物移动的附加层保持同一几何关系。已有服装差分的画布必须使用稳定基准；来源自己的动作位移保留。UI Image 由作者按其布局换算；大小位置不合成进像素。恢复独立模式时参数回到 scale=1、x=y=0，作者原设置仍作为基准。

## 发现与取表面

服务键 `portrait-studio-dynamic-active/1` 类型 `Func<string>`，返回缓存 JSON：公共 header 加 enabled、generation、displays。header 含 protocol、contract、providerId、revision、instance、renderMode。displays 仅列当前活跃显示，字段见 wire Schema。

服务键 `portrait-studio-dynamic-surface/1` 类型 `Func<string, object[]>`，参数 displayId，返回 `[header加display的JSON, 实际主表面, immutableOriginal, UnityEngine.Object[]附加表面]`。该调用只借用引用，不生成图、取写权或变更布局。失效返回 null。借用期间不得修改原图纹理或销毁借用对象。

display 行包含 targetId、displayId、visitId、displayEpoch、claim、mode、candidateId、layout、surfaceType、layerCount，以及可选 originVisitId、session。claim 在登场、释放和失联恢复后更换，阻止旧管理器请求重新接管；它不代替 sender 校验。mode=fault 表示作者回调失败，管理器须保留现图并显示错误，不取得写权。

元数据变化通过 `dynamic-v1` 通道发送 show/state/hide/disabled 提示，消息带 header、generation；hide 还带旧 display 与 reason。管理器只标记待刷新，回调返回后再读取服务和发命令，禁止嵌套接管。漏消息后通过完整快照恢复。空闲最多每0.25秒查询一次元数据；动画每帧不发消息、不重新取表面、不重新序列化快照。generation 不随动画帧变化。

## 控制消息

管理器使用 `ModHelper.SendMessage("PortraitStudio", "dynamic-v1", json)`。作者只监听实际 sender 为 PortraitStudio 的官方消息。每条命令精确填写 header、targetId、displayId、visitId、displayEpoch、claim、session、seq、op。每条上限64 KiB，重复字段与额外字段拒绝。

- select：另含 mode、candidateId、layout。mode 为 source 或 silent；silent 的 layout 必须为默认值。首次 select 建立该 display 的管理会话。只有 applyPolicy 成功返回且收到匹配 ack 才完成交接。source 不把 Sprite 交给管理器播放；silent 成功后管理器才能写此表面。跨来源先 silent 旧来源并确认，再启动新来源。同一表面存在多个动态提供者时，全部竞争者交接成功后才写图；不得仅凭清单静默所有角色。
- renew：延长本 display 会话，至少每秒一次。SDK 租约固定4秒，按单调实时时钟计。无须逐帧发送。
- release：先停止管理器自己的显示、撤销其包装和已借用引用，再发送；作者恢复独立设置并更换 claim。按 ack 或快照确认恢复。重复 release 用新快照核对，不重放旧命令。

同一 session 的 seq 单调递增；相同 seq 与相同报文重试返回缓存 ack，不重复切候选、不延长租约；不同内容复用 seq 或较旧 seq 拒绝。renew 也需要新 seq。ack 含 requestOp、seq、session、最新 display、leaseSeconds；error 含 message 及可取得的请求身份、最新 display。超时或错误不视为成功。

租约到期自动恢复作者独立选择、撤销管理器布局，并更换 claim。管理器写图截止时间必须保守地按发命令的本地时刻+4秒计算；到期前停止写图并释放自己的包装，不能在失去 ack 后继续写。收到 fault 时不续租，保留当前画面，允许重新 select 或等待恢复。隐藏/换人时旧会话失效，禁止在下一个 visit 复用。

## 静态资源与兼容范围

动态清单与 `portrait-studio-provider.json`、`portrait-studio-managed.json` 分开。动态位置不登记 StaticBridge，也不声明 static；作者可另公开独立的静态图片，但不同时登记同一个显示表面的静态写图者。动态帧、图层及过渡纹理不混进静态资源列表。单独导出的 PNG 是静态备选，选中它不保留动画。

管理器只在精确 target 与实际显示对象完成动态握手后退出该范围的旧来源补丁，并恢复其中仍需运行的原方法；不能只跳过新补丁安装却保留已安装的拦截。未公开范围继续走原适配。旧版管理器不认识此声明，作者仍独立运行；若旧管理器有该来源的专用拦截，仍按旧适配运行。声明不承诺未知管理器版本支持动态协议。

作者拥有动态资源内存的分配与释放；此接口不转移纹理所有权。新增 SDK 开销只含少量显示状态与字符串消息。第三方陪同人物、相机、全屏特效需要作者明确区分归属；不能通过一组立绘声明接管公共场景或全局相机。
