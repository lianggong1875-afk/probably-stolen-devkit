# 立绘包制作与演示

静态显示和调整全交给管理器，用 `skills/portrait-studio-managed`；保留已有显示系统用 `skills/portrait-studio-adapter`，制作可独立换图的新包用 `skills/portrait-studio-pack`。详细选择见 [作者入口](作者入口.md)。把对应的整个文件夹、图片和现有工程交给 AI 即可。

动画、自动表情和剧情变图使用 `skills/portrait-studio-dynamic`，保留作者自己的播放和独立设置；动态接口需管理器实现 `dynamic-display-control/1`，接线范例见 [动态说明](examples/dynamic/接线说明.md)。静态路线不把动画声明成静态。

原版顾客可按职业单独换图，也可按共用图片替换。告诉 AI“只换这个职业”或“所有用这张图的人一起换”；详见 [职业与图片键](protocol/原版职业与图片键.md)。

## 制作模组

1. 告诉 AI 要替换哪些人物、通缉照片或场景，以及是否已有模组工程。
2. 托管路线在管理器调整大小位置；原工程接口路线保留原来的换图、大小位置和配置；独立新包由 AI 推荐默认处理方式。有需要你决定的部分时，AI 会用简单的话说明选项。
3. 指定多张候选中的默认图；多套图片可告诉 AI 套装名称及对应角色。独立新包可在游戏设置切换套装，支持通用套装声明的管理器可按套装批量替换。只有固定静态图片进入接口，动画和剧情变图部分保留原处理。
4. AI 完成工程和包检查后，交付运行文件及简短使用说明，写清大小位置在哪调整、检查结果和待验收项。安装或上传按你的要求进行。

新包模板位于 skill 的 `assets/template`，包含独立换图代码；构建工具位于 `scripts`，需要 Python 3.10+ 和 .NET SDK。自定义 NPC 的图片在其创建者提供的显示位置绑定。托管模板使用空入口，不独立换图；制作托管包用该 skill 内的 new_managed.py、managed_validate.py、build_managed.py，依赖支持托管协议的管理器。

新包和托管包可用对应 skill 的 `scripts/framing.py --source <源码目录>` 打开本地构图页，拖动、缩放、选锚点后保存并重新构建。图片保持原样；可载入自己的游戏截图作参照。零依赖独立模板自带可关闭的“去像素化（影响场景画面）”选项：本包替换图实际显示时生效，背景等场景画面也会变化。使用 Portrait Studio 时，也可在游戏设置开启「店内去像素化」。管理器的开关默认关闭，开启后影响整个店内画面，包括立绘和背景。

完整 SDK 可直接双击本目录的「启动立绘调整工具.cmd」，选择 PNG 文件夹或立绘包源码目录。拖动人物调整位置，拖动四角缩放；支持保存进度、PNG 导出和管理器包导出。工具自带 Windows 64 位运行环境，无需安装 Python。详细操作见[立绘调整工具说明](tools/portrait-editor/使用说明.md)。

单独使用 skill 时，也可以双击其 `scripts/启动构图工具.cmd` 调整源码工程；此入口需要本机安装 Python。

可构建工程、接入代码与生成两套范例成品的命令见 [范例入口](examples/范例入口.md)。只把输出的运行包子目录安装到 Mods；源码、说明和构建记录留在开发目录。

## 构建范例
